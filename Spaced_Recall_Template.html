Before you start

A quick note about how this study tool works. You'll only see this once.

1

Your progress lives in this browser, on this device

As long as you keep using the same device and the same browser (this Chrome, this Safari, this Firefox), your cards, schedule, name, and session ID will all stay put. Bookmark this page so you can come back easily.

2

Switching devices or browsers starts you over

If you open this on a different device, a different browser, or in private/incognito mode, you will start fresh from zero. There is no cloud account behind this tool. To keep your streak and progress, use the same device and same browser every time.

3

Print your report regularly as backup

Every week or two, visit the Report tab and click "Print / Save as PDF." Keep the file or paper copy. If your browser ever clears its data (cleared cache, computer wiped, browser uninstalled), your printed reports are the only proof of your work that will remain.
